# H-WING · web (Additium3D)

Web estática (HTML/CSS/JS, sin build). ES/EN con selector; `?lang=en` fuerza inglés.

## Desplegar en Render (Static Site)
1. Sube esta carpeta a un repositorio de GitHub (la raíz del repo = esta carpeta).
2. Render → New → Static Site → conecta el repo.
3. Build command: (vacío) · Publish directory: `.`   (o usa el `render.yaml` incluido: New → Blueprint).
4. El dominio https://dronesmjf.com ya está puesto en canonical, og:image y og:url.
5. Esta versión es pública e indexable (sin `noindex`), con `robots.txt` y `sitemap.xml` para dronesmjf.com.
